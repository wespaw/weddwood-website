# Weddwood

Website for Weddwood, featuring wedding decoration, event styling, portfolio galleries, and contact details.

## Running The Code

Install dependencies:

```bash
npm i
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
